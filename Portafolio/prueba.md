| Versión | Año | Características principales |
|---|---:|---|
| JavaScript original | 1995 | Nació para agregar interactividad a las páginas web. Inicialmente se llamó Mocha y después LiveScript, antes de adoptar el nombre JavaScript. |
| ECMAScript 1 (ES1) | 1997 | Primera edición oficial del estándar. Estableció las bases del lenguaje. |
| ECMAScript 2 (ES2) | 1998 | Introdujo ajustes para alinear el estándar con las normas internacionales, sin grandes cambios en el lenguaje. |
| ECMAScript 3 (ES3) | 1999 | Añadió expresiones regulares, manejo de excepciones con try...catch y mejoras en las cadenas de texto. |
| ECMAScript 4 (ES4) | 2000–2008 | Fue una propuesta para incorporar cambios importantes, pero se abandonó antes de publicarse como estándar oficial. |
| ECMAScript 5 (ES5) | 2009 | Incorporó el modo estricto, mejoras en los objetos, métodos para arreglos y soporte estandarizado para JSON. |
| ECMAScript 5.1 (ES5.1) | 2011 | Realizó correcciones y ajustes para mejorar la compatibilidad con el estándar internacional. |
| ECMAScript 2015 (ES6) | 2015 | Fue una de las actualizaciones más importantes: incorporó let, const, funciones flecha, clases, módulos, promesas y plantillas de texto. |
| ECMAScript 2016 (ES7) | 2016 | Añadió el operador de exponenciación ** y el método includes() para arreglos. |
| ECMAScript 2017 (ES8) | 2017 | Incorporó async/await, Object.values() y Object.entries(), facilitando el trabajo con operaciones asíncronas y objetos. |
| ECMAScript 2018 (ES9) | 2018 | Añadió propiedades rest y spread para objetos, iteración asíncrona y mejoras en las expresiones regulares. |
| ECMAScript 2019 (ES10) | 2019 | Incorporó métodos como flat(), flatMap() y Object.fromEntries(), además de mejoras en el manejo de cadenas de texto. |
| ECMAScript 2020 (ES11) | 2020 | Añadió el encadenamiento opcional ?., el operador de coalescencia nula ??, BigInt y mejoras en los módulos. |
| ECMAScript 2021 (ES12) | 2021 | Incorporó el operador de asignación lógica &&=, ||= y ??=, el método replaceAll() y Promise.any(). |
| ECMAScript 2022 (ES13) | 2022 | Añadió campos privados de clases, el método at(), Object.hasOwn() y el nivel superior de await en módulos. |
| ECMAScript 2023 (ES14) | 2023 | Incorporó métodos no mutables para arreglos, como toSorted(), toReversed() y toSpliced(), además de findLast() y findLastIndex(). |
| ECMAScript 2024 (ES15) | 2024 | Añadió Object.groupBy(), Map.groupBy(), Promise.withResolvers() y mejoras para trabajar con cadenas Unicode. |
| ECMAScript 2025 (ES16) | 2025 | Incorporó métodos auxiliares para conjuntos e iteradores, Promise.try() y atributos de importación, entre otras mejoras. |
